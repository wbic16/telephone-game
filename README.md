# Exocortical Stress Testing — the Exocortical Telephone Game

The standing interop rule for every libphext implementation, and the
program record of the telephone game that enforces it.

- RULE.md — the rule as instituted (Will's words + rulings)
- REPORT.md — the program status document of record
- TOP100.md — TIOBE top-100 snapshot + per-language classification
- harness/ — the game driver, adapter contract, registry
- ports/ — per-language libphext ports + game adapters
- certs/, games/ — game certificates and records

Note: PGP private keys are never stored here. Public keys are inscribed
in the game files themselves (the keys scroll at 1.1.1/1.1.1/1.1.2).
